## ⚡ THE 10-SECOND CHEAT SHEET (highest-value shortcuts in all of Infosys SE)

| Concept | Shortcut to remember | How to remember it |
|---|---|---|
| Successive % change | Net = a + b + ab/100 (use − for decrease) | "**A + B + Product over 100**" |
| % increase then same % decrease | Always a LOSS of a²/100 % | "**Same % up and down = always down**" |
| One item profit r%, another loss r% at same SP | Loss = r²/100 % | "**r-squared loss**" |
| Ratio share | share = Total ÷ (sum of parts) × its part | "**Total ÷ Parts**" |
| Work (efficiency form) | Days ratio 2 : 3 → efficiency 3 : 2 | "**Days up, Speed down (inverse)**" |
| Two people together | 1/T = 1/a + 1/b → T = ab/(a+b) | "**Product over Sum**" |
| Same distance, two speeds | Average speed = 2xy/(x+y) | "**Half-half journey = harmonic**" |
| km/h → m/s | × 5/18 | "**K to M, 5 by 18**" |
| Train crossing pole vs platform | pole: only train length • platform: sum of lengths | "**Pole = alone, Platform = together**" |
| Direction, facing centre in a circle | Left = Clockwise | "**Facing Centre → Left is Clockwise**" |
| Direction, facing outside | Left = Anticlockwise | "**Outside = Opposite**" |
| Morning sun | Sun in East, shadow falls West | "**Morning = E/W shadow**" |
| Clock hands coincide / in straight line in 24 h | 22 times each | "**22, not 24**" |

## 🧠 THE 4 UNIVERSAL TRICKS THAT WIN 6 SECTIONS

> **🧠 MEMORY TRICK 1 — The "DOQU" flow for every OA question**
> **D**ata (write the given numbers), **O**ptions (scan for magnitude), **Q**uestion (underline what is asked), **U**nit (check unit / percent vs value). Most SE mistakes are *units* and *misread questions*, not math.

> **🧠 MEMORY TRICK 2 — "INFY-3" elimination rule**
> Infosys options usually contain: (i) the correct value, (ii) the "forgot-to-divide" value, (iii) the "took wrong base" value. So always test the option that is **exactly one calculation step away** — that is usually the trap.

> **🧠 MEMORY TRICK 3 — Number-series reflex table**
> When you see a series, check in this order: 1) difference, 2) alternate pattern (+a, −b), 3) multiplication/division, 4) squares/cubes ± constant, 5) prime numbers, 6) digits of previous term added. In 90% of Infosys series one of these clicks within 5 seconds.

> **🧠 MEMORY TRICK 4 — Pseudocode "3-column trace"**
> For any pseudo code write only 3 columns → **variable | value | loop count**. Never trace the whole code in your head. Loops print, conditions skip. If a nested loop runs 1+2+3+…+n times, it is the triangle loop (`j = i to n`).
